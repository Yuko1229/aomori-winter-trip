# 青森 冬の一泊二日

青森駅を起点にした1泊2日の旅程ページ。1枚のHTMLだけで動きます。

- **1日目（青森市）** — 津軽海峡・冬景色の歌謡碑、のっけ丼、ねぶたの家ワ・ラッセ、青森県立美術館
- **2日目（十和田市）** — 十和田市現代美術館、アート広場、十和田バラ焼き
- 生ものなしで市場を組み立てるためのネタ一覧
- 出発曜日による休館・定休の早見表（日曜出発は十和田が休館、火曜出発は市場が定休）

## 公開する

GitHub Pages で公開できます。

1. Settings → Pages
2. Source を `Deploy from a branch`、Branch を `main` / `/ (root)` に設定
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で表示されます

## 中身

| ファイル | 内容 |
| --- | --- |
| `index.html` | ページ本体。CSSは全てインライン、外部依存は Google Fonts のみ |

Shippori Mincho / Zen Kaku Gothic New / Roboto Mono を使用。ライトテーマとダークテーマの両方に対応しています。
