青森 冬の一泊二日

青森駅で歌碑とねぶた、十和田でアート。海鮮は加熱でいただいて、りんごは「ふじ」の旬に合わせて。

移動 公共交通＋タクシー 起点 郡山 泊 青森駅前 1泊 帰着駅 七戸十和田

DAY 1青森市歌碑・ねぶた・市場

  • 10:15

    青森駅 着

    郡山を7時台に出る新幹線で、仙台・新青森を経由。新青森から青森駅は奥羽線で6分ほど。

    新青森 → 青森 / 奥羽線 6分
  • 10:30

    りんごA-FACTORY

    駅を出てすぐ。りんごジュースの飲み比べ、アップルパイ、生の「ふじ」もここで確保できます。シードル工房はガラス越しに見学。

    徒歩2分10:00–19:00
    徒歩 5分 / ウォーターフロント沿い
  • 11:00

    津軽海峡・冬景色 歌謡碑

    青函連絡船メモリアルシップ八甲田丸の横。1995年7月建立。ボタンを押すと曲が流れます。目の前が本物の津軽海峡なので、11月以降ならまさに歌のとおりの空の色。

    八甲田丸 9:00–19:00無休
  • 11:45

    のっけ丼（青森魚菜センター）

    食事券を買って、市場の約30店舗を回りながら自分の丼を組み立てる方式。焼きホタテ、炭火の焼き魚、いかメンチ、玉子焼き、惣菜で十分「のっけ丼」になります。加熱ネタは冷めて並ぶこともあるので「今焼いたものある？」と一声。

    12枚 2,200円バラ 190円/枚7:00–16:00（土15:00）火曜定休
    徒歩 5分 / 駅正面へ戻る
  • 13:15

    ねぶたの家 ワ・ラッセ

    実物の大型ねぶたが5台。和紙越しの灯りと、間近で見る鏡絵の迫力はここだけ。館内にショップと食事処もあります。

    大人 620円9:00–18:00最終入場 17:30
    タクシー 約20分 / 三内丸山方面
  • 15:00

    アート青森県立美術館

    開館20周年の企画展「志賀理江子 なぬもかぬも」を2026年10月31日から開催中。奈良美智の《あおもり犬》は屋外なので、雪が積もると見え方が変わります。隣は三内丸山遺跡。

    常設 700円9:30–17:00最終入館 16:30
    タクシー 約20分 / 駅前へ戻る
  • 18:00

    夕食 — 加熱の郷土料理

    ホタテの貝焼き味噌、じゃっぱ汁、焼きホタテ。どれも火を通す青森の定番なので、生ものを外しても選択肢が減りません。駅前に泊まって翌朝すぐ動けるようにしておきます。

DAY 2十和田市現代アート・バラ焼き

  • 08:40

    ホテル発 → 新青森へ

    八戸経由よりも七戸十和田経由のほうが乗車時間が短く、体はずっと楽です。ただし七戸十和田に停まる列車は本数が少ないので、前日に必ず時刻を確認。

    新青森 → 七戸十和田 / 新幹線 約15分
  • 09:40

    七戸十和田駅 着 → タクシー

    駅から美術館まで約20分。駅の物産コーナーは帰りのりんご買い足しに使えます。

    タクシー 約20分 / 十和田市街
  • 10:10

    アート十和田市現代美術館

    作品ごとに部屋が独立した構成なので、自分のペースで座って休みながら回れます。ロン・ミュエクの《スタンディング・ウーマン》、栗林隆の《ザンプランド》など。

    企画展あり 1,800円企画展なし 1,000円9:00–17:00最終入館 16:30月曜休館
    徒歩 すぐ / 道路をはさんで向かい
  • 11:40

    アート広場・官庁街通り

    無料の屋外展示エリア。草間彌生《愛はとこしえ十和田でうたう》の赤と水玉、エルヴィン・ヴルム《ファット・ハウス》などが、雪の白を背景にすると強烈に映えます。官庁街通り（駒街道）はまっすぐな並木道。

    無料屋外
  • 12:30

    昼食 — 十和田バラ焼き

    牛バラ肉と大量の玉ねぎを甘辛いタレで鉄板焼きにする、十和田のご当地もの。市街に提供店が多く、当日決めても大丈夫。

  • 14:00

    りんご買い足し → 帰路

    11月以降は「ふじ」の旬。生のりんごは1日目のA-FACTORYで買っておいて、2日目は七戸十和田駅で加工品を追加するのが荷物的にも楽です。

    七戸十和田 → 郡山
